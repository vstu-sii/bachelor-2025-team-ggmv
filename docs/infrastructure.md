Мониторинг
1. Langfuse (порт 3000)
Что делает: Следит за работой AI-моделей (типа ChatGPT)

Зачем: Чтобы понимать, как работают наши умные штуки

Логин/пароль: смотри в переменных окружения

2. База данных для Langfuse
Что делает: Хранит данные для Langfuse

Зачем: Без нее ничего работать не будет

3. Prometheus (порт 9090)
Что делает: Собирает цифры и метрики

Зачем: Чтобы видеть, сколько памяти ест приложение, сколько запросов приходит и т.д.

4. Grafana (порт 3001)
Что делает: Рисует красивые графики

Зачем: Смотреть на метрики из Prometheus в удобном виде

Логин: admin / admin

5. Loki (порт 3100)
Что делает: Хранит логи (текстовые сообщения от программ)

Зачем: Чтобы читать, что пишет приложение когда что-то ломается

6. Promtail
Что делает: Собирает логи и отправляет в Loki

Зачем: Без него логи никуда не попадут

7. Alertmanager (порт 9093)
Что делает: Отправляет уведомления

Зачем: Чтобы писать в телеграм, когда что-то сломалось

8. Node Exporter (порт 9100)
Что делает: Собирает инфу о сервере

Зачем: Чтобы видеть, сколько процессора занято, сколько свободной памяти

9. cAdvisor (порт 8080)
Что делает: Следит за контейнерами Docker

Зачем: Чтобы видеть, сколько ресурсов ест каждый контейнер




Система
1. Бэкенд (Backend) - порт 8000
Что это: Мозги нашего приложения на FastAPI

Зачем: Обрабатывает данные, работает с базой, делает всю логику

Доступ: http://localhost:8000

Документация API: http://localhost:8000/docs (там будут крутые авто-доки!)

2. Фронтенд (Frontend) - порт 3000
Что это: Красивая часть на React

Зачем: То, что видят пользователи - кнопки, формы, интерфейс

Доступ: http://localhost:3000

3. Jupyter Notebook - порт 8888
Что это: Интерактивная среда для экспериментов

Зачем: Чтобы пробовать код, рисовать графики, тестить идеи

Доступ: http://localhost:8888

Пароль: dev

4. База данных (PostgreSQL) - порт 5432
Что это: Хранилище данных

Зачем: Хранит пользователей, настройки, все важные данные

Данные для подключения:

База: myapp

Пользователь: user

Пароль: password

5. Кэш (Redis) - порт 6379
Что это: Быстрая память для временных данных

Зачем: Ускоряет работу, хранит сессии, кэширует запросы
